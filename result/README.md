・空間認識

テストは2.5秒間のデータ。出力yの積分値から、最も大きい値のインデックスを解答とする

・記憶容量測定
入力u(t)は任意の1次元時系列データ(100msのパルス)
3つのエリアに毎回ランダムにパルスを入力する
教師信号y(t)はu(t-τ)であり、τ秒前のu(t)の時系列データ(パルス)を再現する(同じく1次元ベクトル)
決定係数r^2(τ)について総和を求めたものを記憶容量とする(しかしサンプリングレート依存)
